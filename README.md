A tiny stack virtual machine in Node 22 — a faithful interpreter for make.fun's tiny stack ISA: 32-bit wrapping arithmetic, a 256-value stack, calls, 256 words of memory, and every trap with its own exit code — for [make.fun](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)'s tiny-stack-vm-01-run-20261122 bounty ($100 USDC). Run: it reads `/input/<id>/{program.bin,input.bin}` and writes `/output/<id>/{stdout.bin,exit.txt}` for every instance.
